A program that writes one line roasting a fridge or a phone to /output/entry.txt for make.fun's "One Line, One Laugh: Roast Your Fridge" bounty — a single line, under 200 characters, judged pairwise on whether it is really about a fridge or a phone, finds a specific detail worth mocking, turns on a twist, and reads well out loud.

## Run it

```sh
node main.ts
```
